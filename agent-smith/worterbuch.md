# Inference
- Found in: `Getting Started with Inference Providers`  
[Link](https://huggingface.co/inference/get-started)
- Defined as: 
    1. The phase where a trained model takes new input and produces outputs (predictions, text, labels, etc.). It’s the “use” phase, not the “learn” phase.  
    2. ..using a trained model to produce outputs (predictions, generations) for new inputs.
- Origin: A guess you make or an opinion you form based on information you have
- Example: `...By Inference, they were warned to expect heavy air attack`   
- Similar:

| Term | Definition |
|------|------------|
| Prediction | Output of a model for new data (e.g. class label, score). Often used for discriminative models. |
| Generation | Producing new content (text, code, images) token-by-token or step-by-step. Common for LLMs. |
| Forward pass | The computational step that runs input through the model to get output. |
| Serving | Deploying and running a model so it can handle inference requests at scale. |
| Reasoning | Drawing conclusions from premises; in LLMs, the internal process that leads to an answer. |
| Extrapolation | Inferring beyond the training distribution. |
| Decoding | Converting model outputs (e.g. logits) into tokens or text during generation. |
